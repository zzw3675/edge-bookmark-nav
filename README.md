# ⌘ 书签导航页（Edge 新标签页）

> 把浏览器书签变成美观的新标签页导航：**书签实时同步、自动更新**，二级菜单自动扁平化，支持**浅色 / 深色 / 跟随系统**三种主题，**可自由加载远程导航页**（自己在界面里填网址，随时编辑 / 删除），收藏夹还支持**置顶**。全部数据留在本机，不上传任何服务器。

---

## ✨ 功能特性

| 特性 | 说明 |
| --- | --- |
| 🔄 书签实时同步 | 直接读取 Edge 收藏夹，增删改后新开标签页即最新 |
| 📂 二级菜单扁平化 | 子文件夹自动提升为一级分类，全部显示在左侧栏，点选直达 |
| 🌐 自由加载导航页 | 点「＋ 添加导航页」，自己填名称和网址，自动抓取该页面的链接作为导航分组；随时 ✎ 编辑、删除 |
| 📌 收藏夹置顶 | 悬停收藏夹分类点 📌 即可置顶到最前（重新开标签页仍保持），再点一次取消 |
| 🌓 三模式主题 | 跟随系统 / 浅色 / 深色，一键切换并记忆选择 |
| 🖼️ 网站真实图标 | 自动加载各站点 favicon，缺失时回退为首字母色块 |
| 🔍 快速搜索 | 输入即过滤，`/` 聚焦搜索框，`Esc` 清空 |

## 📦 安装方法（Edge 浏览器）

1. 下载并解压 `书签导航页-浏览器扩展.zip`
2. Edge 地址栏输入 `edge://extensions` 并回车
3. 打开左下角 **「开发人员模式」** 开关
4. 点击 **「加载解压缩的扩展」**，选择解压出来的 `bookmark-nav-extension` 文件夹
5. 完成。**新建一个标签页**，就是你的书签导航页

> 升级方式：在 `edge://extensions` 里找到旧版扩展，点刷新按钮（或先移除再重新加载）即可。

## 🧭 自由加载导航页

1. 点侧栏顶部的 **「＋ 添加导航页」**
2. 填一个名称（可选，不填则用网址主机名）和网址（支持 http / https）
3. 点「确定」，它会自动抓取该页面里的所有链接，作为导航分组展示

- 导航页拉不到内容？点该条目旁的 **✎** 修改网址，或检查服务是否已启动、网络是否可达
- 想删掉？点 ✎ → 「删除」
- 首次使用时内置了两个示例导航源（可自行编辑或删除）

## ❓ 常见问题

- **看不到书签？** 确认 Edge 已登录账号并开启了书签同步
- **导航页加载不出来？** 服务未启动 / 网络不可达 / 网址填错，点 ✎ 改网址后会自动重试
- **网站图标不显示？** 部分网站未提供 favicon，会自动显示首字母色块
- **想换主题？** 点击侧栏右上角的 🌓 按钮，循环切换跟随系统 / 浅色 / 深色
- **书签顺序？** 侧栏顺序自动跟随 Edge 收藏夹里的文件夹排列顺序；想置顶的收藏夹点 📌

## 🛠️ 技术说明

- Manifest V3 Chrome 扩展，兼容 Edge / Chrome 等 Chromium 内核浏览器
- 纯本地运行，`bookmarks` 权限用于读取收藏夹；自定义导航源与置顶设置保存在本机 localStorage，不联网上传任何数据
- 无需构建，无需依赖，零配置开箱即用
